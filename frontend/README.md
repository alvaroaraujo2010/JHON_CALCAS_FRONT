# ContaNexo Front

Frontend en **Angular 21** (landing publica + panel administrativo).

## Requisitos

- Node.js 20+

## Configuracion

La API por defecto apunta a `http://localhost:5000/api` en `src/environments/environment.ts`.

## Ejecutar

```bash
npm install
npm start
```

App: `http://localhost:4200`
